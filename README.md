# 打打印机

面向 Windows 的轻量桌面批量打印工具。支持将 PDF、Word 和图片拖入主窗口或桌面悬浮打印机，自动读取系统打印机并按队列顺序打印。

## 功能

- 桌面置顶卡通打印机，可拖动位置、双击打开主界面、接收文件拖放
- 自动识别并刷新 Windows 已安装打印机
- PDF 自适应可打印区域；Word 使用本机 Microsoft Word 排版打印
- 图片始终等比例显示，绝不拉伸变形；过大时等比例缩小并居中
- 自动识别 PDF、图片的横竖方向；Word 自动沿用文档方向
- 每个文件可单独设置 1-99 份以及自动、横向或竖向
- 设置中支持当前用户开机自动启动，以及最小化/关闭到系统托盘
- 关闭主窗口或从任务栏关闭窗口不会结束进程，程序继续在托盘运行；仅托盘 `Exit` 真正退出
- 托盘右键 `Show Floating Logo` 独立控制悬浮 Logo，悬浮窗不再占用第二个任务栏图标
- 主窗口最小化时悬浮 Logo 保持独立显示，不跟随主窗口最小化
- 桌面悬浮 Logo 水平翻转朝左，文字及其他程序图标保持正常方向
- 悬浮 Logo 或列表空白处右键可粘贴剪贴板图片，并作为普通图片任务预览和打印
- 剪贴板读取、像素转换和 PNG 保存全部在独立后台线程执行，并包含占用重试和超大图片保护
- 列表支持桌面式图标预览：图片缩略图、PDF 首页缩略图、Word 系统类型图标
- 支持逐项勾选、多选、全选和取消全选，打印时仅处理已勾选文件
- 鼠标悬停缩略图时显示最高 720px 高清大图，并根据屏幕高度自动调整，移出后立即关闭
- 托盘右键使用 JavaFX 中文菜单，包含打开主界面、显示悬浮 Logo、开机自动启动和退出程序
- 批量队列、份数设置、逐文件状态、失败不中断、停止后续任务
- 所有耗时打印均在单后台线程运行，避免界面卡顿

## 环境与运行

需要 JDK 17、Maven 3.9+；Word 文件打印需要安装 Microsoft Word。PDF、图片打印不依赖 Word。

```powershell
$env:JAVA_HOME='D:\Code_Tools\jdk-17.0.16'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
mvn clean test
mvn javafx:run
```

支持格式：`.pdf`、`.doc`、`.docx`、`.png`、`.jpg`、`.jpeg`、`.bmp`、`.gif`。

## 打包说明

生产发布建议用 JDK 17 的 `jpackage` 生成自带运行时的 Windows 安装包，避免用户单独配置 Java。首次运行时系统/打印机驱动可能弹出权限或打印确认窗口。
